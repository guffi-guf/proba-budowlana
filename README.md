# D&M Renovation website

Open index.html in a browser. The site uses plain HTML, CSS and JavaScript, with no package installation or build step.

The website stays inside one centered frame. The top tabs switch between full-frame views in place. Each view uses a full-bleed photograph or, for Locations, a satellite map centered on 10 Kirby Close, London N11 3FE. The Services tab brings together six photo-led service cards based on the supplied screenshot: plumbing, electrical works, full renovation, garden works, carpentry/handyman work, and painting/decorating.

The six service photographs are generated illustrative images. Replace them with genuine company project photos before presenting them as completed work.

## Before publishing

- Confirm the published service area around 10 Kirby Close, London N11 3FE.
- Replace [Your phone number] and [Your email address] with the company's contact details.
- CONTACT_EMAIL (top of script.js) is set to dominika@dmrenovations.net. The enquiry form opens a prefilled email in the visitor's email app; it does not submit to a server.

The header uses the supplied transparent logo at assets/dm-renovation-logo-transparent.png.
